# tvbian.com

One page: what TVBian is, why it exists, what it runs on, how to help. Clean, concise, with some
character. Generated from this repo and hosted on GitHub Pages, with `tvbian.com` pointed at it.

## Why it exists, the page's argument

- Major distros cannot scale their contribution process to one-off Chinese TV boxes: upstream device
  trees, patch series across several projects, months of review, and a branch that moved meanwhile.
  Nobody does that for a $30 box.
- TVBian is built for the opposite: a board is one directory and one pull request, and the bring-up
  is AI-assisted. The person who owns the box adds it, not the board's maker.
- The aim: Linux, and whatever runs on it, on hardware already in people's hands, and less e-waste
  from Android boxes abandoned by their makers on day one.
- The name is TV Box Debian. Any board fits; the process is shaped for an owner doing the bring-up.

## Sections, top to bottom

1. **The name and the one-line pitch**, with the e-waste angle.
2. **Sponsored**: commercial bring-up and store links to buy a supported box. Empty at first, with
   an email to ask; the maintainer vets each by hand. ❓ the address, one at `tvbian.com`.
3. **Supported boards**: a photo each, its SoC, and its image link; generated from `firmware/*/` and
   the latest release, so it never lists a board the repo does not ship.
4. **Contribute**: the best contribution is a board, one PR; then fixes and docs.
5. **Report an issue**: what to include, a serial boot log above all.
6. **Donate**: pays for AI time and the maintainer's, through a trusted platform: GitHub Sponsors
   beside the repo, or Open Collective. ❓ which.

## Build and hosting

- Generated by a workflow from the repo, published to GitHub Pages; no hand-edited HTML to drift.
- `tvbian.com`: a `CNAME` file in the Pages output, and DNS at the registrar: an apex `A`/`AAAA` set
  to GitHub Pages' addresses, `www` as a `CNAME` to `sormy.github.io`; HTTPS from Pages.
- Board photos from `docs/<board>/`, resized at build time.
